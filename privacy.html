Privacy Policy — rclone-sync-ethan

Last updated: 21 October 2026

This application is a personal-use OAuth client operated by a single individual to synchronise files between a personal computer and that individual's own Google Drive account. It has no other users and is not distributed to third parties.

Data accessed

With your authorisation the app requests Google Drive access, allowing it to read, create, modify and delete files in the Google Drive account you authorise.

How data is used

Solely to perform file synchronisation operations initiated locally by the operator. No file contents, metadata or account identifiers are transmitted to the developer or any third party.

Storage

OAuth credentials (access and refresh tokens) are stored only on the machine running rclone, in its local configuration file, protected by operating system account permissions. No Google user data is stored on any server controlled by the developer.

Sharing

No data is shared, sold or transferred to any third party. Google user data is not used for advertising and is not used to develop, improve or train machine learning models.

Limited Use

This app's use of Google user data is limited to the practices described in this policy and complies with the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data remains in your Google Drive until you delete it. Authorisation can be revoked at any time at myaccount.google.com/permissions, which immediately ends the app's access. Local credentials can be removed with rclone config delete <remote>.
